# DOOK内置AI能力与日报生成偏好调研

调研日期为2026-11-13。

## 参考实现

- **Notion AI Autofill**在具体数据库字段内提供摘要、翻译、提取和自定义填充。用户可以保存该字段的配置并选择手动或随页面变化运行。该交互适合DOOK参考：用户从熟悉的业务入口运行AI，在该入口附近调整要求。 [Notion AI Autofill](https://www.notion.com/help/autofill#basic-autofill)
- **Agent Skills**以含`SKILL.md`的目录打包指令，可附带脚本、参考资料和静态资源。规范按名称和用途描述、完整指令、按需资源三步加载；客户端接入指南还涉及技能发现、重名优先级和激活机制。DOOK的“写日报”已经明确表达意图，业务代码可以直接选择日报指令；如果以后支持在通用入口里选择或推荐多个技能，再让用途描述参与选择。 [Agent Skills规范](https://agentskills.io/specification#progressive-disclosure) · [客户端接入指南](https://agentskills.io/client-implementation/adding-skills-support)
- **OpenAI API的提示词指南**建议将内置提示词放进应用代码并管理版本，用类型化或已校验的参数组装动态输入，通过代表性样例评估提示词。对DOOK，可将日报默认规则随应用发布，将个人偏好保存在本机，并在主进程组装调用所需内容。 [OpenAI提示词指南](https://developers.openai.com/api/docs/guides/prompting#prompts-in-your-application)

## 方案比较

| 方案 | 用户操作与适用场景 | 开发取舍 |
| --- | --- | --- |
| 内置默认＋日报生成偏好 | 点击“写日报”直接生成。需要调整时，查看默认规则、填写行文或篇幅要求，也可恢复默认。 | 依托现有业务入口，少量设置即可复用同一偏好。适合验证用户实际会改哪些内容。 |
| 结构化格式设置或多个日报模板 | 用户选择个人回顾、团队汇报等预设，或指定段落标题和顺序。 | 适合格式要求稳定或同一用户反复切换受众的情况。固定标题、段落顺序和任务状态由应用渲染，结果更容易核对。 |
| 完整提示词编辑 | 用户可以查看并修改整段生成指令，表达任意写作约定。 | 编辑灵活，每次调整都可能与输出契约发生冲突。需要额外设计版本升级、冲突提示和恢复默认。 |
| 通用Agent Skills | 用户能导入、分享或通过通用入口激活技能，技能可携带参考资料和脚本。 | 跨工具复用时价值明确，需要明确格式兼容范围、资源访问和激活机制。 |

建议先采用内置默认加可选的“日报生成偏好”。设置处可显示默认写法和一份示例，用户能填写诸如“每项一句话，保留项目名称，语气简洁”的要求，清空即可恢复默认。应用负责选取任务、统计、检查来源和拼装格式，模型负责在给定事实和约束内整理事项。若要保证用户指定的标题和顺序，则将它们作为模板字段交给应用渲染。查看生成依据可沿用日报规格中的日期、数据截至时间、统计与素材范围说明。 [日报规格](../specs/ai-daily-report.md)
