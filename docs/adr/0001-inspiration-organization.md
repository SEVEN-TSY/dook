# 灵感以日期和主题两种视角归集

2026-10-28讨论记录；2026-11-01根据灵感分组导航改版更新呈现决定；2026-11-02按界面细节调整更新默认视角、输入和列表。

灵感用于留住突然冒出的主意，具体含义可以暂不明确，例如产品构想或突然想到需要补充的需求。任务侧重今天的工作规划，灵感不提供转任务流程；统一保留“灵感”，不拆分“想法／速记”，避免快速记录时额外分类。

## 日期归集

- 日期视角按记录日期归集，今天及前6天按日期倒序导航；每次展示一个分组。
- 7天之外的记录统一进入“历史灵感”；现有旧数据没有记录时间，无法还原日期的也归入该组。
- 修改正文、追加补充或调整主题不改变原始记录日期。
- 长列表通过下滑逐页加载，避免一次展示全部记录。

## 主题归集

- 主题视角位于日期视角之前并作为默认，首次进入及重启选择“未归类”；每次展示一个分组。
- 主题是相关独立灵感的具名集合，允许长期积累，未来可据此整理项目需求，无需一开始就对应具体项目。
- 新增灵感只需输入内容，可暂不归入主题；可独立创建主题，也可在归集灵感时创建主题。
- 允许取消对某个主题的归集；日期视角和主题视角均可操作归集及取消归集。
- 一条灵感允许归入多个主题，作为低频操作提供；同一灵感在不同主题中展示时，内容修改同步更新。
- 主题改名仅在主题视角操作。

## 编辑与补充

- 列表点击正文原地编辑，正文最多展示两行，超出省略，编辑时完整展开。
- 日期组和主题组内的灵感均按记录时间从新到旧排列。
- 新增及原地编辑保留textarea，初始一行；有内容且可编辑时提供清除叉号，清空当前草稿并恢复焦点。Enter提交、Ctrl+Enter换行、输入法保护、失焦保存和失败保留输入沿用原规则。
- 普通及已归档列表均移除详情、补充展示及追加入口。已有补充数据与相关接口继续保留，小记仍允许持续补充。
