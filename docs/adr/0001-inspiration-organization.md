# 灵感以日期和主题两种视角归集

2026-10-28讨论记录：以下为已确认的设计决定，尚未实施。本轮设计先独立记录于此，不同步修改正式需求或术语表。

灵感用于留住突然冒出的主意，具体含义可以暂不明确，例如产品构想或突然想到需要补充的需求。任务侧重今天的工作规划，灵感不提供转任务流程；统一保留“灵感”，不拆分“想法／速记”，避免快速记录时额外分类。

## 日期归集

- 默认按记录日期归集，今天及前6天按日期倒序展示，今天默认展开，其余日期默认折叠，各日期可独立展开。
- 7天之外的记录统一进入默认折叠的“历史灵感”；现有旧数据没有记录时间，无法还原日期的也归入该组。
- 修改正文、追加补充或调整主题不改变原始记录日期。
- 长列表通过下滑逐页加载，避免一次展示全部记录。

## 主题归集

- 可切换为独立的主题视角，直接按主题归集展示，并提供“未归主题”；所有主题组默认折叠。
- 主题是相关独立灵感的具名集合，允许长期积累，未来可据此整理项目需求，无需一开始就对应具体项目。
- 新增灵感只需输入内容，可暂不归入主题；将灵感归集到新主题时创建主题。
- 允许取消对某个主题的归集；日期视角和主题视角均可操作归集及取消归集。
- 一条灵感允许归入多个主题，作为低频操作提供；同一灵感在不同主题中展示时，内容修改同步更新。
- 主题改名仅在主题视角操作。

## 编辑与补充

- 列表点击正文原地编辑，正文最多展示三行，超出省略，编辑时完整展开。
- 日期组和主题组内的灵感均按记录时间从新到旧排列。
- 行尾“补充”按钮打开右侧详情面板，保留现有右侧面板形态。
- 详情展示完整原始想法、历史补充和追加输入框；原始想法只读，移除详情中的“编辑原始想法”功能。

## 尚未讨论

主题之间的排序、空主题的处理、视角切换后的展开状态是否保留，以及历史组内部的呈现方式尚未确定，不将其视为已确认需求。项目创建和需求生成流程也尚未展开设计。
