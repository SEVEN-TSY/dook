# 模型API接入检查

2026-11-13记录，待后续评估。

- **限制重复请求**。连接测试的按钮禁用状态只约束界面操作。可在主进程合并同一配置进行中的连接测试，评估全局并发上限和短冷却时间，并限制保存验证的排队数量，避免重复调用和计费。
- **限制响应体大小**。当前请求有60秒总超时和生成Token上限。可按解压后的实际字节数限制响应体，边读边计数，超限时停止读取、丢弃结果并提示响应过大。具体字节上限待评估。
- **先加密再验证API Key**。先在内存中用系统能力加密，成功后再发验证请求，验证通过后才写入本地。系统加密失败时可省去一次可能计费的请求。
- **降低连接测试成本**。如果测试只需确认Key和模型可用，可关闭推理并限制输出长度。若需要验证所选推理强度，可保留对应的测试能力。
- **校验结构化业务结果**。接入日报等功能时，即使开启JSON模式，也要解析结果并校验字段及任务来源。空响应、截断或校验失败时保留原草稿。
- **传输层重试与网络提示（已实现）**。网络失败、408、429和5xx按800毫秒、2秒的指数退避自动重试，单次超时也重试，累计90秒后不再发起新尝试；鉴权、余额、证书校验和用户取消不重试。失败信息按错误码区分域名解析失败、无网络、连接被拒、连接中断、连接超时和证书问题，重试用尽时附带次数。一次调用仍只写一条`ai_call_logs`记录，重试次数不单独统计。
