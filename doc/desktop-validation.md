## 自动化入口

运行`npm test`验证应用服务、真实SQLite、迁移和MCP；运行`npm run smoke`构建并在独立目录完成首次操作与重启恢复两阶段真实Electron验证。已构建后可用`node scripts/run-smoke.mjs drag`单独验证靠近边缘和自由区域的连续1px拖动、重复拖动及松手后内容尺寸保持不变。

`node scripts/run-smoke.mjs dock`单独验证左、右、上三边吸附前后以及收起再展开后的窗口内容与便签表面宽高一致，同时验证悬停呼出胶囊、沿边拖动、松手不展开、离开恢复细条和点击展开。该独立场景还验证胶囊仅展示完成数和总任务数，以及完成比例不包含多天任务的部分进度，截图保存为`note-capsule-left.png`、`note-capsule-right.png`和`note-capsule-top.png`。完整smoke也运行贴边交互检查。

## Windows外壳与物理多屏人工验收

`node scripts/run-smoke.mjs lifecycle`验证贴边窗口销毁后不会继续轮询已销毁窗口；`dock`场景通过真实动画起止位置验证胶囊进入和退出均保持整体尺寸、进入时向内推出、退出时反向推回边缘，退出时淡出并在完成前隐藏独立细条。同时验证胶囊到便签采用共享表面投影和圆角校正、文字不跟随缩放、过期完成握手失效，并保存`note-morph-<edge>-<fraction>.png`供分段视觉检查。

这些项目需要可交互的实际桌面及显示设备；自动化模拟不能代替物理插拔。

- 启动后确认便签无系统标题栏、菜单栏及独立工具栏，任务栏没有便签入口，通知区域只有一个myTodo图标；托盘打开主界面后，主界面正常出现在任务栏。
- 从便签顶部空白拖动，确认图钉、关闭叉号、任务输入和勾选不会拖动窗口；关闭自由置顶后便签仍可拖动且普通窗口能盖住它。
- 在实际双屏上跨接缝拖动不吸附，左、右、上外侧吸附，底边不吸附；分别试验错位屏幕及不同缩放比例。
- 悬停入口查看胶囊统计时，在其他应用输入文字，确认键盘焦点不被抢走；点击展开便签，按住胶囊沿边拖动并确认松手不展开；输入、编辑、托盘菜单及应用内删除确认期间不收起。
- 在自由摆放、贴边展开、收起三种状态分别拔屏及调整分辨率，确认便签和入口仍可触达；主动隐藏时不被屏幕变化唤出。用旧屏幕布局保存后，断开该屏再启动，确认先展开到可见位置。
- 关闭两端窗口后确认可从托盘恢复；输入有效内容后直接从托盘退出，重启确认保存成功。

当前自动化结果记录不声称已完成以上物理设备人工验收。
