# 今天任务

`TasksPage`由主界面与桌面便签共用。`useTasks`读取列表、协调完成/删除并订阅主进程通知；`useTaskInput`按一轮输入绑定真实任务，串行保存并追赶保存期间的新输入，保留失败内容，避免重复创建。

点击输入框外、失焦和回车触发保存，单纯移开鼠标不保存。输入框外的点击使用document捕获阶段监听，窗口内不可聚焦的空白位置也可触发；成功后清空新增栏或结束行内编辑，Esc不取消编辑，失败保留内容。生命周期请求通过相同保存入口提交并回复。设置页及贴边收起时任务组件继续挂载，保留输入和保存订阅。便签仅保留内容区图钉与隐藏控件，主界面提供设置及恢复便签入口。

界面不访问数据库，也不创建MCP客户端。

行内编辑与普通描述共用字体、行高、内边距和换行规则。隐藏的同样式文字撑起布局，textarea覆盖在原位；焦点底色和阴影描边不占布局空间。进入编辑只在挂载时把光标置于末尾，后续渲染保留用户选择的光标位置。
