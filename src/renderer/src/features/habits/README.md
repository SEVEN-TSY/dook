# 习惯管理

`HabitsPanel`在主界面展示习惯列表和创建入口，通过DesktopApi读取及保存，不在界面执行每日调度。

有效输入在提交、失焦及主界面生命周期保存时创建习惯；保存接入TasksPage的单一保存协调器，失败保留输入。习惯产物在两端任务列表中显示“来自习惯”。

每日生成由主进程启动、跨日时调用AppService，核心服务使用注入的本地时钟。HabitRepository将习惯创建、今天任务及生成记录放入事务，同一习惯每天至多生成一次；删除任务不删除生成记录。

主界面支持编辑和删除习惯；今天任务在双窗口均可添加为习惯，事务复用原任务并登记当天生成记录。删除习惯保留历史任务的来源标识及内容。新建与编辑输入共用一个保存入口，聚合到TasksPage的生命周期保存握手。
