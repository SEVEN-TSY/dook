# 核心层

`AppService`是IPC与MCP共享的应用入口，提供任务、子事项、习惯和灵感用例及基础设施诊断。TaskStore、HabitStore和InspirationStore通过构造参数注入，具体SQL位于storage层，时钟可注入以验证本地日期切换。核心层不导入Electron、React或MCP SDK。

今天任务不跨日延续；多天任务未完成时持续显示，完成当天保留、次日起隐藏。手动进度达到100%时完成；有子事项时按完成比例计算，整条勾选与全部子事项在事务中联动。首个子事项创建与任务转换原子执行。编辑和完成不改变所属日期或创建顺序。

习惯创建当天立即生成任务，启动和跨日补齐当天，不补历史日期。独立的每日生成记录保证完成、删除和重启后不重复生成。从今天任务添加习惯复用原任务，习惯、关联及当天记录一并提交。修改、删除习惯仅影响后续生成，已生成任务保留。

灵感独立于任务日期，支持编辑原始想法及按顺序追加补充；补充输入的一轮保存使用稳定标识避免重试重复。所有输入校验和业务规则通过公开服务入口执行。
