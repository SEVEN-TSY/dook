# 桌面适配层

`Desktop`统一拥有双窗口注册表、唯一托盘及隐藏/退出保存握手。`NoteController`管理便签置顶、吸附、展开收起和显示器变化恢复；纯几何规则集中在`note-geometry`，偏好通过`preferences`持久化。

展开状态吸附只调整位置，保留窗口内容和便签表面的宽高。界面用平移将边缘留白从6px收至1px，保持原来的margin和高度计算，避免内容区域被拉宽、拉高。展开恢复期间临时锁定内容尺寸，完成后解除，避免Windows分数缩放把外框取整差值带入内容区域。

`SaveBarrier`向对应渲染窗口请求提交输入，只有原窗口的回复能解除等待；失败或超时保留窗口。主进程完成握手后才隐藏或清理资源。IPC仅接受注册窗口主Frame，不在此编写业务SQL。自启动留待后续。
